# Botanical tasting-note assets

Generated 28 October 2026 using the built-in image-generation tool (not the CLI and not Higgsfield). Four original transparent PNG triptychs were converted to WebP with alpha preserved using cwebp, quality 85. The soft circles are CSS behind the images. These evoke flavour and aroma, not organic certification, ingredients or allergens. In particular, Volcano Oolong's hazelnuts illustrate a nutty aroma only; the brand ingredient list does not list nuts.

Product facts were checked against https://chaludrinks.com/ on 28 October 2026. The Rosé page gives a blend overview because the source does not publish a complete ingredient declaration. The supplied skincare screenshot informed the three-part presentation only.
